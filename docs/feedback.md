# How to provide V4 feedback

AWS SDK for PHP V4 is in development. Focus feedback on use cases and API
design. Comment on
[the V4 design preview pull request](https://github.com/aws/aws-sdk-php/pull/3408)
with design feedback, use cases, and preview documentation errors.

## Feedback details

Include:

1. The application or library type.
2. The AWS services and workflows involved.
3. A short example of how you would like the API to look.
4. How the proposal compares with your V3 code.
5. Constraints imposed by frameworks, dependency injection, static analysis,
   testing, long-running workers, or deployment environments.
6. Whether the issue is a preference or a blocker.

## Use the appropriate channel

- Treat snippets on this branch as design proposals.
- Comment on the V4 design preview pull request for feedback and documentation
  errors.
- Follow [SECURITY.md](../SECURITY.md) for potential security issues.
