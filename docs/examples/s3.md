# Amazon S3 typed operations

Status: **Illustrative proposal**

```php
use Aws\S3\Input\GetObjectRequest;
use Aws\S3\Input\PutObjectRequest;
use Aws\S3\S3Client;
use Aws\S3\S3ClientConfig;
use Psr\Http\Message\StreamInterface;
use Smithy\Http\Message\ResourceRequestStream;

$s3 = new S3Client(new S3ClientConfig(
    region: 'us-west-2',
));

$uploaded = $s3->putObject(new PutObjectRequest(
    bucket: 'example-bucket',
    key: 'documents/hello.txt',
    body: ResourceRequestStream::fromFile('/path/to/hello.txt'),
    contentType: 'text/plain',
));

printf("Uploaded with ETag %s\n", $uploaded->eTag);

if (isset($uploaded['ETag'])) {
    printf("V3-style access: %s\n", $uploaded['ETag']);
}

$downloaded = $s3->getObject(new GetObjectRequest(
    bucket: 'example-bucket',
    key: 'documents/hello.txt',
));

$body = $downloaded->body;
try {
    if ($body instanceof StreamInterface) {
        while (!$body->eof()) {
            echo $body->read(64 * 1024);
        }
    } else {
        echo $body;
    }
} finally {
    if ($body instanceof StreamInterface) {
        $body->close();
    }
}
```

Example output for a text file containing `Hello from S3.`:

```text
Uploaded with ETag "5891b5b522d5df086d0ff0b110fbd9d2"
V3-style access: "5891b5b522d5df086d0ff0b110fbd9d2"
Hello from S3.
```

The `['ETag']` lookup reads the typed output directly through
`ReadonlyArrayAccessTrait`. It does not perform a conversion.

The same operation can also accept a typed input hydrated from a V3-shaped
array. When an application needs an actual array value, it can convert the
output recursively:

```php
$upload = PutObjectRequest::fromArray([
    'Bucket' => 'example-bucket',
    'Key' => 'documents/hello.txt',
    'Body' => ResourceRequestStream::fromFile('/path/to/hello.txt'),
    'ContentType' => 'text/plain',
]);

$uploaded = $s3->putObject($upload);

$uploadedArray = $uploaded->toArray();
```

## What this illustrates

- Service-specific client configuration.
- Typed operation input and output.
- Named constructor arguments and typed output properties as the primary API.
- Direct V3-style output introspection through read-only array access.
- V3-shaped input construction and recursive array conversion as separate
  compatibility options.
- Replayable streaming uploads and incremental response consumption.
