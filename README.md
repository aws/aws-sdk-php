# AWS SDK for PHP V4

> [!IMPORTANT]
> This branch is under construction. It holds work in progress on the next
> major version of the AWS SDK for PHP. Use
> [Version 3](https://github.com/aws/aws-sdk-php/tree/master) for all
> applications.

## Status

| Area | Status |
| --- | --- |
| SDK implementation | In progress |
| Composer package | Unreleased |
| API compatibility | Unstable |
| Production support | V3 only |

Code on this branch changes often. Names, signatures and behavior can change
or be removed at any time before V4 is released.
